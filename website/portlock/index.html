What you get

Soft lock

Blocks new thumb drives. Sticks already plugged in stay live so copies finish safely.

Hard lock

Kill switch for all mass storage — the “I’m leaving the house” button.

Attempt log

Every plug-in is recorded (VID/PID, serial, product) with a desktop notification.

Install

Public apt repository. One command adds the source; then install the package like anything else.

Recommended — with sudo 
# add the Portlock apt repo, then install
curl -fsSL https://gtdataworks.com/portlock/install-apt.sh | sudo bash
sudo apt update
sudo apt install gtdataworks-portlock
portlock
Forgot sudo? (goat mode) 
# no sudo on the curl line — the script elevates itself
curl -fsSL https://gtdataworks.com/portlock/install-apt.sh | bash
sudo apt update
sudo apt install gtdataworks-portlock
portlock
Goat mode: if you forget sudo on the installer, it detects you’re not root and re-runs itself elevated. You’ll still need sudo for apt install (that’s apt being apt).

Auto-lock ruleset

Designed so locking the screen never murders a copy mid-write.

  1. Unlock the session and plug the stick before you lock the screen.
  2. Lock screen → soft-lock: active sticks stay authorized; new sticks are blocked and logged.
  3. Unplug while locked → you cannot re-insert until ports open again.
  4. Unlock session → ports open (optional). Manual hard-lock survives until you unlock ports yourself.

Not USBGuard

USBGuard is a full USB authorization framework. Portlock is a focused desktop product: mass-storage soft/hard lock, tray UX, and attempt logging. Complementary tools — different jobs.
