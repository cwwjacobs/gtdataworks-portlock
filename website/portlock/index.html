policy / lockwrite-safe

A stick already writing is not torn down when the screen locks.

Soft lock
New sticks blocked. Active sticks stay authorized.
Hard lock
Leave-the-house — all mass storage off.
Unplug while locked
Cannot re-insert until ports open.
Log
VID/PID, serial, product, lock state.

Ruleset

Lock the screen. Keep the copy.

Plug in while the session is unlocked. After that, Portlock treats new removable storage as untrusted until you unlock again.

  1. Unlock, then plug the stick you actually need.
  2. Lock screen → soft-lock. Active sticks keep writing. New ones are blocked and logged.
  3. Unplug while locked and the port stays closed to that stick.
  4. Unlock the session → ports open. A manual hard-lock stays until you clear it.

Install

Add the repo. Then apt install.

Add the apt source, then install the package. apt still needs sudo either way.

With sudo

# add the Portlock apt repo, then install
curl -fsSL https://gtdataworks.com/portlock/install-apt.sh | sudo bash
sudo apt update
sudo apt install gtdataworks-portlock
portlock

Without

# installer elevates itself if you are not root
curl -fsSL https://gtdataworks.com/portlock/install-apt.sh | bash
sudo apt update
sudo apt install gtdataworks-portlock
portlock

One-shot package: gtdataworks-portlock_1.0.0_all.deb · then sudo apt install ./gtdataworks-portlock_1.0.0_all.deb · upgrade with sudo apt update && sudo apt install --only-upgrade gtdataworks-portlock
